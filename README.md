#### Godotゲームエンジンの操作方法
必ず覚えておくべき操作方法は次のようになる
-  シーンの作成
-  ノードの追加・削除
-  スクリプトの作成・接続・キャラクターを動かす
-  シーンのインスタンス化
-  シグナルの接続
-  TileMapLayerの編集	ステージを作成する
-  CollisionShape2Dの設定	衝突判定を実装する
-  アニメーションの作成	歩行やジャンプを表現する
- インスペクターの操作	ノードの設定を変更する
